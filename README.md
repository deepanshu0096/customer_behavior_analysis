Data Analytics Project
Overview

This project demonstrates an end-to-end Data Analytics workflow using Python, SQL, and Power BI. The project includes data loading, exploratory data analysis (EDA), data cleaning, SQL analysis across multiple database systems, dashboard creation, and report generation.

The objective of this project is to transform raw data into meaningful insights through analytics and visualization techniques.

Dataset

The dataset used in this project contains structured data for analysis purposes. It was loaded into Python for preprocessing and later stored in different SQL databases for querying and analysis.
